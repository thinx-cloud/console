## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend `/stats`, `/stats/today`, `/logs/*` → dashboard | Server JSON is parsed into component state; metric extraction and timeline parsing treat the shape as untrusted |
| build item → download `<a href>` | The build download URL is derived from server-provided `build_id` / `raw` fields and placed into an `href` attribute |
| range selector click → chartRange | `chartRange` is set only by three fixed-value `@click` handlers (7/31/365) — no user-typed value reaches the chart |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-02-01 | Tampering | build download `href` from server data | mitigate | The `href` is built via `buildDownloadUrl` from `build_id`/`raw`; the link uses `target="_blank"` with `rel="noopener"` to prevent reverse-tabnabbing. Vue attribute binding does not execute the value. If the resolved URL is empty/non-http the row renders a `text-muted` "—" instead of a link. |
| T-05-02-02 | Information Disclosure | metric numbers + audit messages rendered in DOM | accept | All values reach the DOM through Vue `{{ }}` interpolation which auto-escapes; no `v-html` is introduced. Audit/build text is the user's own platform data behind authentication. |
| T-05-02-03 | Denial of Service | dashboard load with a slow/failing endpoint | mitigate | `loadData` uses `Promise.allSettled` over `fetchDashboard` (itself `allSettled`) + `fetchToday` + `fetchDevices`; a single failing endpoint degrades one card/widget to 0/empty rather than blanking the page. |
| T-05-02-04 | Tampering | range selector setting `chartRange` | mitigate | `chartRange` is mutated only by three hardcoded `@click="chartRange = 7|31|365"` handlers; the `CheckinsTimeline` `range` prop additionally has a `validator` restricting it to 7/31/365 (Plan 05-01). No arbitrary value path exists. |
| T-05-02-SC | Tampering | npm/pip/cargo installs | accept | This plan installs NO new npm packages. The chart is provided by `CheckinsTimeline.vue` (Plan 05-01) which uses the already-pinned `vue-chartjs`/`chart.js`. No package-manager install task exists in this plan. |
</threat_model>
