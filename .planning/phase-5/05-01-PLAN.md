## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| backend `/stats` response → stats store | Server-provided JSON is parsed into `state.stats`; the `timeline` object shape is treated as untrusted and guarded with `|| {}` / `|| []` |
| stats store → CheckinsTimeline props | `checkins` array flows from backend data through Vuex into the chart component; only `record.date` is read, parsed via `new Date()` and discarded if invalid |
| CheckinsTimeline → chart canvas | Aggregated numeric counts are passed to vue-chartjs; no user-supplied string is rendered as HTML |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-05-01-01 | Denial of Service | fetchDashboard parallel fetch | mitigate | `Promise.allSettled` (not `Promise.all`) ensures a single slow/failing endpoint cannot reject the whole dashboard load; the page still renders with partial data. |
