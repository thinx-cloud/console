<objective>
Fix the TransformerEditor.vue post-save behavior to redirect to the transformer list, and harden base64 encode/decode in both the editor and store for UTF-8 safety.

Purpose: After a successful save, the editor currently stays on the page and shows a green banner (this.saved = true). Per D-04, the correct UX is to clear hasChanges and navigate to /app/transformers so the user sees their updated list. Additionally, the current btoa(body) in updateItem and atob(transformer.body) in loadTransformer are not UTF-8 safe per D-05 — adding the standard unescape/encodeURIComponent wrappers prevents InvalidCharacterError when transformer bodies contain non-ASCII characters.

Output: TransformerEditor.vue redirects on save; transformers.js updateItem uses UTF-8-safe btoa; TransformerEditor.vue loadTransformer uses UTF-8-safe atob.
</objective>
