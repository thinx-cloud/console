<objective>
Fix the POST body bug in the transformer store that causes all save operations to fail silently, then add the duplicate alias guard to the create modal.

Purpose: Every transformer write operation (create, update, delete) calls saveTransformers, which currently wraps the array in `{ info: { transformers } }`. The backend's owner.js process_update checks `body.transformers` at the top level and ignores `body.info.transformers` — so all writes are currently no-ops. This is the root cause of all transformer save failures. The alias guard (D-03) prevents creating transformers with duplicate aliases.

Output: Fixed transformers.js store; Transformers.vue with working duplicate alias detection and inline modal error.
</objective>
