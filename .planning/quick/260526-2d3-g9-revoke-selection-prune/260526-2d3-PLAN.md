# Quick Task 260526-2d3 — G9: Per-row Revoke selection prune

**Source:** Phase 11 Wave 2, ROADMAP.md L368-L369 / L383. Filed during Phase 9 UAT.

## Problem

`vue/src/pages/Devices/Devices.vue` per-row Revoke (`revokeRow`, ~L306) calls
`loadData()` on success but does not remove the revoked udid from
`this.selectedUdids[]`. Result: after revoking a selected device row, the
toolbar counter `Revoke ({{ selectedCount }})` still includes the now-deleted
udid until the user manually clicks the row again. Bulk Revoke (`confirmRevoke`,
~L249) already does the right thing by resetting `selectedUdids = []`.

## Fix

Mirror the existing in-file splice pattern from `toggleDevice` (L234-L235):

```js
const i = this.selectedUdids.indexOf(udid);
if (i > -1) this.selectedUdids.splice(i, 1);
```

Inserted into `revokeRow` between `this.message = 'Device revoked.';` and
`this.loadData();`. Keeps array identity (consistent with `toggleDevice`),
zero new dependencies, single function.
