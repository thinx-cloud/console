# Quick Task 260520-w52: Fix secondary button background color to darker blue

## Objective

The `secondary` Bootstrap theme color is `rgba(#F4F4F5, .9)` — nearly white. Buttons using
`variant="secondary"` (Build, Cancel/Close in modals) have white text on a near-white background,
making them illegible. Change `secondary` to a darker blue so these buttons are readable.

## Tasks

### Task 1: Update secondary theme color in _variables.scss

**File:** `vue/src/styles/_variables.scss`

**Action:** Change line 58 from:
```
secondary: rgba(#F4F4F5, .9),
```
to:
```
secondary: rgba(#3461C1, .9),
```

`rgba(#3461C1, .9)` is a medium-dark blue that contrasts well with white text and sits visually
between `primary` (#2477FF) and `$teal`/`info` (#4179CF).

**Acceptance criteria:**
- `_variables.scss` line containing `secondary:` now uses `rgba(#3461C1, .9)` (or equivalent darker blue)
- Build and Cancel buttons are visually distinguishable from the white/light background
- White text on secondary-variant buttons is legible

## must_haves

- `vue/src/styles/_variables.scss` contains `secondary: rgba(#3461C1, .9)`
