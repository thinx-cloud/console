# Summary: Fix secondary button background color to darker blue

## What was done

Changed the `secondary` Bootstrap theme color in `vue/src/styles/_variables.scss` from
`rgba(#F4F4F5, .9)` (near-white, ~rgba(244,244,245,0.9)) to `rgba(#3461C1, .9)` (medium-dark blue).

## Why

Buttons with `variant="secondary"` (Build, Cancel/Close in modals) had white text on a near-white
background — the text was nearly invisible. A darker blue provides adequate contrast for white text.

## Files changed

- `vue/src/styles/_variables.scss` — line 58: `secondary` color value updated

## Affected buttons

- Build button in `Devices.vue` (device table row)
- Build Firmware and Back to Devices in `DeviceDetail.vue`
- Modal Cancel/Close buttons site-wide (use secondary variant by default in BootstrapVue modals)
